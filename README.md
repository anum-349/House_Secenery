# 🏡 House Scenery – Python Turtle Project

This project creates a **beautiful 2D house scenery** using the **Python Turtle graphics library**. It combines various graphical elements such as a house, roof, windows, trees, clouds, sun, grass, and flowers to generate a detailed and visually appealing scene.

---

## 🌟 Features

* Draws a **detailed house** with roof, walls, and windows.
* Includes **trees, grass, and flowers** for a natural environment.
* Sky, **sun**, and **clouds** are added for a realistic outdoor scenery.
* Uses **custom colors** for a vivid and artistic output.
* Demonstrates **loops, recursion, and Turtle graphics** techniques.
* Fully interactive and adjustable by modifying parameters in the script.

---

## 🛠️ Technologies Used

* **Python 3** – Programming language for drawing and logic.
* **Turtle Graphics** – For creating 2D graphical output.

## 🚀 How to Run

1. **Clone the repository**:

```bash
git clone https://github.com/anum-349/House_Secenery.git
cd House_Secenery
```

2. **Install Python** (if not already installed).

3. **Run the script**:

```bash
python u.py
```

4. **View the output** – A detailed house scenery with trees, sun, clouds, and flowers will appear.
